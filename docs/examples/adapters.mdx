## Image preparation

Core and React read the 64 × 48 image directly. Scene adapters render at 384 × 288, then reduce to 64 × 48 before applying CRT. That filtering can change colors even when the final dimensions match.

[Scene settings](/scenes) cover input resolution and color handling. [Options](/options) lists presets and overrides.
