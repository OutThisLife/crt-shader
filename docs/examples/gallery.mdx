## Compare like with like

- **Article examples:** compare digital input, the actual photographed reference, and the live reconstruction. A photograph includes the camera and signal path as well as the CRT.
- **Peach examples:** retain the distinctions between original pixels and the different photographed display/signal combinations discussed in the [follow-up article](https://datagubbe.se/crt2/).
- **itch.io artwork:** judge reconstruction against the original artwork. These examples are not measurements of a physical display.
- **Photo inputs:** downsampling is preparation chosen by the user, separate from the reconstruction preset.

The renderer uses the same frozen presets as the package. A different crop or prepared resolution can change the image even when the preset name is the same; see [options and presets](/options) and [image geometry](/images#geometry-and-low-level-rendering).

## Asset provenance

Article photographs, game sprites, and itch.io artwork are not covered by the shader’s MIT license. Consult each example’s source attribution and the [credits](/CREDITS) before reusing an image. The standalone npm package excludes these gallery/reference assets.
