## Choose an integration

These examples run in a browser app with a bundler such as Vite and WebGL 2. Each preview runs its example code; no image download is needed.

## Inputs

Images keep their native pixels by default. For photographs, set `inputMode="photo"` and a numeric `inputResolution`. Scene adapters reduce their input automatically when `inputResolution="auto"`.
