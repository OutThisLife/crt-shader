## Install and render

```sh
npm install crt-shader
```

Run this in browser code with a canvas in your page and a same-origin image URL:

```js
import { createRuntime, prepareInput } from 'crt-shader';

const runtime = createRuntime();
const image = await runtime.loadImage('/artwork.png');
const source = prepareInput(image);

await runtime.render({
  source,
  output: document.querySelector('canvas'),
  preset: 'reference',
  width: 960,
  height: 540,
});

// When no further updates are needed:
runtime.dispose();
```

The prepared input retains native pixels by default and composites transparency on black. Rendering needs WebGL 2 and Canvas 2D. Output dimensions are physical pixels, not CSS dimensions.

Retain the runtime for updates. Increment `sourceVersion` when mutating an input canvas, and regenerate the prepared input if the original source changed. Remote images require CORS permission.

The [core and image API](/images) is the canonical reference for preparation, scheduling, cache invalidation, cropping, errors, and resource ownership. [Options and presets](/options) describe effect settings independently of input preparation.
