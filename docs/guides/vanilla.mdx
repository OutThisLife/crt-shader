## Install and render

<span id="runnable-example-source" />
<Quickstart integration="vanilla" />

Keep the runtime for updates. After changing an input canvas, prepare it again and increment `sourceVersion` in the next `runtime.render()` call. Output dimensions are physical pixels.

For an image URL, use `await runtime.loadImage(url)` instead of drawing a source canvas; remote URLs need CORS permission.
