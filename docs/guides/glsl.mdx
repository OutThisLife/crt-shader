## Import the stages

```sh
pnpm add crt-shader
```

```js
import { vertex, horizontal, vertical, optics } from 'crt-shader/glsl';
import { PRESETS } from 'crt-shader/presets';
```

The host must prepare the input, allocate intermediate targets, bind uniforms, and run `horizontal`, `vertical`, then `optics` as separate passes.

Follow the [GLSL stage contract](/glsl) for dimensions, sampling and color transfer, and the [porting guide](/agents/PORTING) for resource ownership and GPU checks.
