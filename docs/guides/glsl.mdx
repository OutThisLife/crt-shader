## Import the stages

```sh
npm install crt-shader
```

```js
import { vertex, horizontal, vertical, optics } from 'crt-shader/glsl';
import { PRESETS } from 'crt-shader/presets';
```

These are GLSL ES 3.00 source strings, not a ready-made single-pass material. The host must prepare the input, allocate intermediate targets, bind uniforms, and run horizontal → vertical → optics in order.

Use the existing [GLSL stage contract](/glsl) for target dimensions, sampling, orientation, and color transfer. Use the [agent porting guide](/agents/PORTING) for ownership and real-GPU verification. No WebGPU, Unity, or Godot port is implied by these exports.
