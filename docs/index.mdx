Add the skill to your coding agent:

```sh
npx skills add OutThisLife/crt-shader
```

Then ask for what you want:

> Put a CRT effect on the hero image.

> Add a CRT pass to my R3F scene, low-res and soft.

The agent installs the package and wires it into your stack.

## Manual setup

Needs WebGL 2 and a bundler like Vite.
