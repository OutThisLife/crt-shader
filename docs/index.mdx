`crt-shader` reconstructs images through horizontal signal filtering, brightness-dependent scanlines, and display optics. It is a WebGL 2 pipeline with image, React, Three.js, pmndrs, and React Three Fiber entry points.

The photograph includes the display, signal, camera, and viewing conditions. This is an artistic reconstruction inspired by the articles—not a measurement of that monitor or a claim to reproduce every CRT. The [Peach follow-up](https://datagubbe.se/crt2/) explains why signal quality and camera focus matter.

## Use it in your application

```jsx
import { CRTImage } from 'crt-shader/react';

<CRTImage src="/artwork.png" alt="Pixel-art landscape" width={480} />
```

Images preserve their native pixels by default. Photo reduction is opt-in. **Scene adapters downsample by default** with `inputResolution="auto"`; choose a numeric input resolution to control that separately from the CRT effect. Output is opaque RGB on a black matte.
