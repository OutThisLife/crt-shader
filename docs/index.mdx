CRT rendering for images and 3D scenes. Requires WebGL 2 and a browser app with a bundler, such as Vite.

[Gallery](/examples/gallery/) · [npm](https://www.npmjs.com/package/crt-shader) · [GitHub](https://github.com/OutThisLife/crt-shader)

Using a coding agent? Add the skill and ask it for a CRT effect. It installs the package and the peers for your stack:

```sh
npx skills add OutThisLife/crt-shader
```
